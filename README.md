# Customer Churn Prediction

A classification model to predict customer churn using structured 
behavioral data, built with a focus on EDA-driven feature engineering 
and model comparison.

## Approach
- Exploratory Data Analysis (EDA) to identify key churn indicators
- Feature engineering and preprocessing
- Trained and compared Logistic Regression and Decision Tree models
- Evaluated using accuracy, precision, recall, and confusion matrix

## Tech Stack
Python, Pandas, scikit-learn, Matplotlib, Seaborn
